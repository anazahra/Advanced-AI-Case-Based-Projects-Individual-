# 📘 Case-Based from the Advanced Artificial Intelligence Course (Individu)

Proyek ini merupakan tugas **individu** pada mata kuliah **Advanced Artificial Intelligence** yang berfokus pada penerapan pendekatan **case-based machine learning**.  
Seluruh eksperimen dilakukan menggunakan **dataset dari Kaggle**, mencakup studi kasus **klasifikasi**, **regresi**, dan **klastering**.

---

## 🔹 Classification Case
**Weather Type Prediction**

- Menerapkan model klasifikasi untuk memprediksi **jenis cuaca** menggunakan dataset cuaca sintetis dari Kaggle.  
- Melakukan praproses data berupa normalisasi fitur numerik dan encoding variabel kategorikal.  
- Mengevaluasi performa model menggunakan **akurasi**, **F1-score**, dan **confusion matrix**.  
- Menganalisis hasil klasifikasi untuk mengidentifikasi kelebihan dan keterbatasan model.

---

## 🔹 Regression Case
**House Price Prediction**

- Menerapkan model regresi untuk memprediksi **harga rumah (medianHouseValue)** berdasarkan fitur geografis, demografis, dan ekonomi.  
- Melakukan praproses data melalui pemilihan fitur dan persiapan data sebelum pemodelan.  
- Menghasilkan prediksi nilai target serta menyusun berkas *submission* sesuai format Kaggle.  
- Mengevaluasi performa model menggunakan **Root Mean Squared Error (RMSE)**.

---

## 🔹 Clustering Case
**Unsupervised Clustering Challenge**

- Menerapkan pendekatan **unsupervised clustering** untuk mengelompokkan data tanpa label.  
- Melakukan normalisasi fitur menggunakan **StandardScaler**.  
- Mengimplementasikan algoritma **K-Means** untuk menentukan klaster tanpa mengetahui jumlah klaster sebenarnya.  
- Menyusun hasil prediksi klaster ke dalam berkas *submission* sesuai format yang ditentukan.
